# 围起来 · 桌面围棋

低矮漆木桌上一张 9 路围棋盘，黑白两支小军队自己下一整盘围棋，带自动导播镜头。小朋友也可以接管一方亲手下。适合一年级小朋友，界面全是儿童版大白话。

```sh
npm install
npm run dev        # 开发服务器
npm test           # 规则引擎 + AI 测试（Node，无需浏览器）
npm run build      # 打包到 dist/（站点路径 /weiqi/，可用 BASE_PATH 覆盖）
npm run preview    # 本地预览打包结果
```

在线地址：https://ahjdzx.github.io/weiqi/ —— 推送到 `main` 后由 GitHub Actions（`.github/workflows/deploy.yml`）先跑测试、再构建并发布到 GitHub Pages。

## 规则（中国规则 · 数子法）

- 9 路棋盘，黑白轮流落子，黑先；白贴 5.5 子。
- 气尽提子；自杀禁着；简单打劫（提一子后对方不能立即回提，停一手解除）。
- 双方各停一手终局，或同型三现、步数上限（500 手）保底终局；数子分胜负。
- 记谱用 A–J（跳过 I）+ 数字坐标，如天元 E5。

## AI

- 估值用「势力图」：每颗棋子向四周辐射影响（被对方棋子挡住则衰减），影响超门槛的点算作地盘，加上子数即中国规则数子。打入对方势力圈因此有意义。
- 候选点试摆打分：地盘涨跌 + 提子奖励 + 打吃奖励 − 送吃惩罚 − 回到见过的旧局面重罚；按深度档取前 14/24/40 个候选，softmax 按温度抽选（温度滑杆在界面上叫「爱冒险」）。
- 领先时对方停一手则跟着停；收官没油水时主动停一手；同型三现由引擎判终局。
- 种子驱动一切随机：同一种子复现同一盘；「重演一遍」按对局脚本精确重放。

## 分层（严格单向）

```
src/engine/go.js    规则引擎：纯逻辑，不依赖 Three.js
src/ai/             rng 种子随机数 · evaluate 势力图估值 · brain 候选打分与温度抽选 · commentary 儿童版解说
src/game/match.js   一盘对局：唯一能改变对局状态的入口 commit()，只接受合法落子
src/sim/            show 演出协程（落子弹跳、提子飞盒）· fx 尘土与闪光
src/render/         world 桌子棋盘木盒 · stones 云子 · director 自动导播
src/main.js         总控：引擎决定 → AI 选择 → 演出 → 导播
```
